# @workspace/docs

Documentation site for `@dldc/styles`, built with Vite and
[`@deno/vite-plugin`](https://jsr.io/@deno/vite-plugin).

## Tasks

```sh
deno task --cwd=docs dev      # start the dev server (http://localhost:5173)
deno task --cwd=docs build    # production build to docs/dist
deno task --cwd=docs preview  # preview the production build
```
